# Results

This directory distinguishes the values reported in the manuscript from files generated by a local run.

Tracked files:

- `paper_results.csv`: per-image results reported in the manuscript.
- `paper_summary.csv`: mean results reported in the manuscript.

When `scripts/run_experiment.py` is executed, it also creates local files such as:

- `segmentation_results.csv`
- `summary_results.csv`
- per-case folders containing masks and comparison figures.

Those generated files are ignored by Git and are not intended to be committed automatically.

The tracked paper tables were checked against a complete local run of all nine experiments and agree with the generated results to the precision displayed in the manuscript.
